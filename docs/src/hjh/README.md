# [画江湖]·破晓 —— 盘灵古域插件化重启计划

> 自数据包版本停更后，我们带着全新的项目回来了。  
> 所有盘灵核心机制已全面转为插件，稳定、便捷、可扩展。  
> 原贴讨论：[https://tieba.baidu.com/p/10906537957](https://tieba.baidu.com/p/10906537957)

## 目前已完成内容

### 主线任务 · 新手引导重做
- 原版主线剧情 + 圣兽试炼 现已纳入 **新手教程**。
- 采用 **左键对话 / 右键交易** 的简洁交互方式。
- 无论你是盘灵老玩家，还是完全没接触过的新人，都能快速融入。

### 圣兽试炼 · 全面重写
- 四大圣兽试炼机制翻新，战斗更有挑战性。
- 通关后可获得 **专属圣兽饰品**，兼具收藏与实用价值。

### 种族与职业 · 史诗级重构
- **五大种族** 全部重做，每个种族新增 **主动技 + 被动技**，战斗策略大幅提升。
- **原炼丹师拆分为两大职业**：
  - **术士** —— 输出侧，擅长元素与爆发伤害。
  - **医师** —— 辅助侧，专注治疗与增益。

### 区域机制 · 野怪生态填充
- 为以下三大区域增加了 **专属野怪机制**：
  - 南方 · 炎砂沙漠
  - 西方 · 虎爪山脉
  - 北方 · 玄水湖泊
- 探索不再单调，处处皆有遭遇战。

### 基础功能 · 全面升级与新增
- **修改系统**：炼丹、锻造、画重晶等机制优化。
- **新增系统**：
  - 种植 / 采集
  - 坊市交易
  - 占卜
  - 点歌
  - 称号系统
- **正在制作中**：钓鱼系统（即将上线）
